# 📜 Automated Email Sender & Certificate Generator Agent

An end-to-end Python automation agent for cleaning recipient data, generating personalized high-resolution PDF certificates, and dispatching them via Gmail SMTP with detailed logging.

---

## 📁 File Structure & Naming Conventions

To ensure the pipeline runs smoothly, keep the following file names and folder structures in your root directory:

| File / Directory | Mandatory Name | Description |
| :--- | :--- | :--- |
| **Raw Student Data** | `students.csv` | Input CSV file containing at least `name` and `email` columns. |
| **Cleaned Data** | `students_clean.csv` | Auto-generated by `clean_data.py` after cleaning & validating emails. |
| **Certificate Template** | `template.pdf` | Base PDF certificate template (A4 Landscape format recommended: 842 × 595 points). |
| **Environment Config** | `.env` | Created from `.env.example`. Contains private Gmail SMTP credentials. |
| **Requirements** | `requirements.txt` | Python package dependencies (`pymupdf`, `pandas`, `python-dotenv`, `reportlab`, `pillow`). |
| **One-Click Runner** | `run.bat` | Windows batch script to run the full pipeline in one click. |
| **Output Directory** | `output/` | Directory where generated student certificate PDFs are stored (`<Student_Name>.pdf`). |
| **Dispatch Audit Log** | `send_log.csv` | Log file generated during email sending to record success/failure status. |

---

## ⚙️ Setup & Installation

### 1. Install Dependencies
Make sure you have Python 3.8+ installed. Install required packages using:
```bash
pip install -r requirements.txt
```

### 2. Configure Gmail SMTP (`.env`)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Open `.env` and fill in your Gmail address and 16-character **App Password**:
```env
GMAIL_ADDRESS=your_email@gmail.com
GMAIL_APP_PASSWORD=xxxx_xxxx_xxxx_xxxx
```
> 💡 **Note**: Do not use your regular Gmail account password. Generate an **App Password** from your Google Account security settings (*Security -> 2-Step Verification -> App Passwords*).

## 🚀 How to Run (Single Command / One Click)

### Option 1: Double-Click `run.bat` (Windows One-Click)
Simply double-click **`run.bat`** in File Explorer, or run in terminal:
```cmd
.\run.bat
```

### Option 2: Python Command
Run the master orchestrator script:
```bash
python main.py
```

> **What happens when you run `main.py` or `run.bat`?**
> 1. Automatically cleans and validates `students.csv` -> generates `students_clean.csv`.
> 2. Automatically generates personalized PDF certificates for all students into `output/`.
> 3. Automatically emails each student their certificate via Gmail SMTP and logs the results in `send_log.csv`.

## 🎯 How to Calculate & Find Text Position Coordinates (`NAME_X`, `NAME_Y`)

In `generate_certificates.py`, the student name is placed onto the PDF template using page coordinates:

```python
NAME_X = 421.0  # Center position horizontally on A4 Landscape (842 / 2)
NAME_Y = 270.0  # Vertical position down from top of the page
```

### 📐 Understanding PDF Page Coordinates (PyMuPDF / fitz)
- **Standard A4 Landscape PDF Size**: `842 points` wide × `595 points` high (72 points = 1 inch).
- **Origin `(0, 0)`**: Top-Left corner of the PDF page.
- **`NAME_X`**: Horizontal distance in points from the left edge.
- **`NAME_Y`**: Vertical distance in points from the **top edge down to the text baseline**.

---

### 🛠️ Suggested Tools & Websites to Get Coordinates

#### 1. **Photopea (Free Web App)** — *(Recommended)*
- **Website**: [photopea.com](https://www.photopea.com)
- **Steps**:
  1. Go to Photopea and open your `template.pdf` or certificate image.
  2. Open **Info Panel** (*Window -> Info*).
  3. Hover your mouse cursor over the exact baseline where student names should appear.
  4. Note the pixel dimensions `(X_px, Y_px)` and total image size `(Image_Width, Image_Height)`.
  5. Convert pixels to PDF points using the formula below.

#### 2. **Figma / Canva (Design Editors)**
- **Website**: [figma.com](https://www.figma.com) | [canva.com](https://www.canva.com)
- If designing in Figma or Canva using an **842 × 595 pt canvas** (or standard A4 landscape frame), the position values shown directly in the design inspector map 1:1 to PDF points!

#### 3. **Adobe Acrobat Pro / PDF-XChange Editor**
- Open `template.pdf` in Adobe Acrobat or PDF-XChange.
- Use the **Measuring Tool** (*Tools -> Measure*) to measure exact distances from top and left edges in inches or mm.
- Convert inches to points: `Points = Inches × 72`.

---

### 🧮 Conversion Formula (Pixels to PDF Points)

If your editor gives coordinates in pixels `(X_px, Y_px)` for an image of size `(Image_Width, Image_Height)`:

```text
NAME_X = (X_px / Image_Width) * 842
NAME_Y = (Y_px / Image_Height) * 595
```

#### Example Calculation:
If your template image is `1920 × 1357` pixels and the name baseline is at `X = 960 px`, `Y = 615 px`:
- `NAME_X = (960 / 1920) * 842 = 421.0 pt` (exact center)
- `NAME_Y = (615 / 1357) * 595 = 269.5 pt`
